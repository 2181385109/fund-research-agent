# 已知局限（LIMITATIONS）

按阶段追加。每条写明影响范围和对应的 ADR。

## 数据采集（S1）

1. **AkShare 1.18.97 取不到申购费率**：`fund_fee_em(indicator="申购费率")` 恒返回空表。原因是 AkShare 按东方财富费率页的小标题取表，但代码只认「申购费率（前端）」，页面现在的标题是「申购费率」。本项目不修改 AkShare 源码，改从招募说明书的费率表解析申购费分档（ADR-027）。因此申购费数据的时效等于最新一版招募说明书，而不是销售平台的实时展示；表格版式无法解析的份额记为缺口。
2. **AkShare 1.18.97 的人事公告接口在 0 条结果时报错**：`fund_announcement_personnel_em` 对没有公告的基金抛 `Length mismatch`，流水线把它当作空结果（ADR-027）。
3. **东方财富接口是非官方接口**：公告列表（JJGG）、净值、排行等接口没有稳定性承诺，字段可能变化；流水线固定 AkShare 版本、本地缓存原始结果，接口变化时直接报错而不是静默补值。
4. **披露 PDF 取自东方财富转载件**：证监会基金电子披露网站从本机命令行不可达（PLAN §2.1），PDF 使用 `pdf.dfcfw.com` 上由基金管理人发布的转载件，MANIFEST 记录 URL 与 sha256。
5. **LOF 按场外份额收录**：160219、161035 是 LOF，只使用场外 A/C 份额的净值和费率，不涉及场内交易价格（ADR-030）。
