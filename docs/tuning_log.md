## S4 检索调参协议（2026-09-29，在跑第一次 dev 之前写定并提交）

- **数据**：`fund_qa_v1` 的 dev 集（冻结版 sha256 `77fb06a9…`）。评测 answerable 且有 evidence 的题，共 30 题（dev 33 题中排除 unanswerable 3 题）。
- **主指标**：hybrid_rerank（生产默认模式）在 dev 上的 **nDCG@10**；MRR@10 作参考。每次尝试都跑全部 5 种模式，其余模式的数字只作记录，不参与决策。
- **调参项与顺序**（PLAN §5 S4 规定的 4 项）：
  1. 实体过滤：开 / 关
  2. 上下文头：开 / 关（向量字段 `embedding_ctx` / `embedding`，BM25 字段 `text_ctx` / `text`，重排输入带不带头）
  3. 查询指令前缀：开 / 关
  4. 每路召回数 vector_k = bm25_k ∈ {20, 50, 100}
  采用逐项坐标下降：起点是基线（实体过滤开、上下文头开、指令前缀关、每路 50、重排候选 20、top_n 10）；每一项在前几项已定的基础上比较。
- **决策规则**：只有当 dev nDCG@10 提升 **≥ 0.01** 时才改变该项，否则保留基线值（n=30，更小的差异按噪声处理）。
- **固定不调**：RRF k=60（PLAN 固定）、重排候选数 20、top_n 10、重排模型 bge-reranker-base、向量模型 bge-small-zh-v1.5。
- **test**：四项都定下来后，在 test 上**只跑一次**最终配置（5 种模式，外加主对比 vector vs hybrid_rerank 的配对 bootstrap）；次要消融「实体过滤 开 vs 关」也只跑一次。test 的结果不再回头影响任何配置。
