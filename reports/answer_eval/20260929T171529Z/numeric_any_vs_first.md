# numeric 题：any 与 first 不一致的逐条说明

口径（ADR-046，用户 2026-09-30 定）：numeric 主口径 = **first**（回答里第一个与 gold 单位种类相容的数字是否落在容差内）；**any**（任一相容数字落在容差内）只作参考。
README 与结论里的准确率只引用 first。本文件对 any ≠ first 的每一道题（两个配置各自）说明原因；「答案是否正确」一栏是**执行者（我）逐条阅读回答原文后的判断**，不是自动判分，也不进任何指标；回答原文在同目录 `<配置>/answers.jsonl`，判分记录在 `<配置>/scores.jsonl`。

统计（来自 `summary.json` → `results.<配置>.numeric_sensitivity`，n = 47：50 道 numeric 里去掉 3 道最新净值题，那 3 题单独用实时净值对照判分）：

| 配置 | first（主口径） | any（参考） | any ≠ first 的题数 |
|---|---|---|---|
| hybrid_rerank | 33/47 | 46/47 | 13 |
| vector | 34/47 | 43/47 | 9 |

**结论**：first 是保守口径，会把「答案是对的、但正确数字不是回答里第一个数字」的回答判错。逐条读下来：hybrid_rerank 的 13 题里 **12 题回答本身是对的**（first 误判），**1 题（qa-0055）回答确实是错的**（any 碰巧命中）；vector 的 9 题**全部**回答本身是对的。所以 first 的 70.2% / 72.3% 是**下界**，不代表 Agent 答对的比例；我把它作为主口径报告是遵照决定，读结论时请连同本文件一起看。

## 原因分类

**A. 回答先给出一个背景数字（基金只数、总数）再给答案**
- `agent-0005`（两个配置）：问「销售服务费年费率不低于 0.6% 的 C 类份额有几个」，回答开头先说「基金池共 20 只基金，对应 20 个 C 类份额」，然后「**不低于 0.6% 的有 8 个**」。gold 8 只。答案正确。

**B. 回答先列出表格（多个同类数字）再给结论 / 平均值**
- `agent-0019`（两个配置）：问「指数型基金 A 类份额平均管理费年费率」，回答先列 7 只基金各自的费率（0.50%、0.80%……），再给平均值 0.914%。gold 0.914%。答案正确。
- `agent-0028`（hybrid_rerank）：问最大回撤，回答用表格先给「区间收益率 29.71%、年化 42.90%」，再给「最大回撤 -27.64%」。gold -27.64%。答案正确。（vector 的回答第一个数字就是它，first 判对。）
- `agent-0029`（两个配置）：问年化收益率，回答表格先给「区间收益率 200.28%」，再给「年化收益率 73.68%」。gold 73.68%。答案正确。
- `qa-0016`（hybrid_rerank）：问持有满 7 天不满一年的赎回费，回答先列完整赎回费率表（1.5% / 0.5% / 0.25% / 0%），再指出适用 0.5%。gold 0.5%。答案正确。
- `qa-0017`（两个配置）：问申购金额 100–200 万的申购费率，回答先列分档表（1.20% / 0.60% / 0.40%…），再指出 0.60%。gold 0.60%。答案正确。
- `qa-0046`（hybrid_rerank）：问业绩比较基准二季度涨跌，回答先给基准构成「65% × 中证医药卫生指数 + 35% × 债券指数」（65、35 被抽成数字），再给「-4.48%」。gold -4.48%。答案正确。

**C. 回答先陈述一个相关的上限 / 偏离度数字（合同条款里同一句话有两个数）**
- `agent-0056`、`agent-0057`、`agent-0058`、`qa-0061`（两个配置）：条款写法是「日均跟踪偏离度绝对值不超过 0.35%（或 0.5%），年跟踪误差不超过 4%（或 8%）」，回答按原文顺序先给 0.35% / 0.5%，再给 4% / 8%。gold 分别是 4%、8%、4%、4%。答案都正确（回答里明确写了「年跟踪误差不超过 …」）。

**D. 回答先写一个区间再写上限**
- `qa-0059`（两个配置）：问港股通标的股票投资比例上限，回答写「股票资产的 0%–50%，即上限为 50%」，第一个数字是区间下限 0%。gold 50%。答案正确。

**E. any 碰巧命中：回答是错的（first 判错是对的）**
- `qa-0055`（hybrid_rerank）：问天弘中证医药 100 **A 类**截至二季度末过去一年净值增长率，gold -8.91%。回答写「A 类 -9.09%」，并说「C 类 -8.91%」——把两个份额张冠李戴了，回答错误；-8.91% 出现在回答里，any 才判对。这是 any 会高估的典型例子（dev 小样里的 qa-0050 是同一类问题）。vector 配置在该题上 first 与 any 一致。

## 顺带发现的判分器误判（不属于 numeric，如实记录，未改口径）

- `qa-0101`（hybrid_rerank，entity 类）：问「哪只每年允许的收益分配次数更多」，回答用表格先列工银前沿医疗股票（4 次），再列富国中证医药主题指数增强（6 次），结论明确写「富国中证医药主题指数增强每年最多 6 次，更多」。gold = 富国中证医药主题指数增强，回答正确；但判分器规则是「标准答案先于其他候选基金出现」，表格里工银在前，被判错。这是 entity 二选一规则的误判，hybrid_rerank 的 entity 准确率 0.941（16/17）因此偏低一题。

## 不是判分器误判的错误（两个配置共同或各自的真实错误）

- `agent-0020`（两个配置）：问「二季度末同时出现在至少 3 只基金前十大重仓股里的股票有多少只」，gold 23，两个配置都答 21。any 与 first 一致（都判错）。没有对 Agent 写的 SQL 与 gold_sql 逐条比对，原因未查明。
- vector 独有的检索类错误：`qa-0008`（托管费）、`qa-0047`、`qa-0053`（季报净值增长率）三题回答「现有资料中没有找到」，`qa-0023` 给出了错误的任职日期（2018-06-20，gold 2021-12-08）；这四题在 hybrid_rerank 下都答对了。any 与 first 都判错。
